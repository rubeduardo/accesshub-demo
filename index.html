Sobre o AccessHub

Tecnologia aplicada à organização e à inclusão.

A

Uma ideia que nasceu de uma necessidade real.

O AccessHub é um projeto idealizado por Rubens Eduardo a partir de uma iniciativa de organização digital de cadastros e carteirinhas associativas, tendo como contexto a ADEMOC — Associação das Pessoas com Deficiência de Montes Claros.

A implementação original foi concluída utilizando planilhas e banco de dados local, com funcionalidades de cadastro, controle, numeração única, emissão e consulta de carteirinhas.

Esta versão web é uma demonstração independente, criada para apresentar o conceito de forma interativa. Ela não é o sistema operacional da ADEMOC, não contém seus registros e não possui integração com a associação.

Privacidade por design: esta demonstração utiliza exclusivamente dados fictícios armazenados no navegador. Não insira dados pessoais reais.
